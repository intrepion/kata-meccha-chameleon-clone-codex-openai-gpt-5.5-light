# Paint colors carry gameplay rules

Paint will be more than a cosmetic decal: Paint Colors will carry gameplay rules for traversal, gates, and camouflage. The MVP will start with a small set of rule-bearing colors so the game has a strong identity without turning the first implementation into an unbounded systems sandbox.

## Considered Options

- Cosmetic paint only.
- Paint for camouflage only.
- Paint for gates only.
- Paint for grip or traversal only.
- Paint as a compact rule system combining camouflage, gates, and traversal permissions.

## Consequences

The level design must teach colors as rules, not just visual feedback. Automated browser checks should exercise at least one paint-driven traversal rule, one paint-driven gate, and one camouflage consequence.
