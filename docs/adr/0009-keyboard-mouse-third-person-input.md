# Keyboard and mouse third-person input

Meccha Chameleon will use keyboard movement, mouse camera control, and click-based paint or tongue targeting. This matches the third-person 3D browser pattern and gives Raycast Aim a clear relationship to what the camera sees.

## Considered Options

- Keyboard movement, mouse camera, click paint and tongue.
- Keyboard movement, fixed camera, click paint and tongue.
- Mouse-only movement and actions.
- Gamepad-first input.
- Touch-first input.

## Consequences

Browser tests should cover keyboard movement and camera-facing pointer interactions. Touch and gamepad support are later enhancements, not acceptance criteria for the first playable clone.
