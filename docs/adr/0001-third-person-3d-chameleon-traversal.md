# Third-person 3D chameleon traversal

We will build Meccha Chameleon as a third-person 3D traversal game with orbit camera movement, jumping, collision, and browser-verifiable interaction instead of a top-down, side-scrolling, first-person, or fixed-camera approximation. The clone promise depends on inhabiting a nimble chameleon in space, so the camera and movement model are part of the product identity rather than a presentation detail.

## Considered Options

- Top-down or isometric browser game.
- Side-scrolling 2.5D platformer.
- Third-person 3D traversal with orbit camera.
- First-person paint puzzle.
- Fixed-camera room puzzle.

## Consequences

Movement, paint targeting, tongue targeting, and collision must be tested through a real browser path, because build success alone will not prove the game feels like a 3D chameleon traversal game.
