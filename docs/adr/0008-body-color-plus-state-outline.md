# Body color plus State Outline

The Chameleon will communicate Paint Color and Camouflage state through body color plus a State Outline instead of body color alone, HUD-only feedback, particles-only feedback, or no explicit feedback. Body color alone can disappear against the same painted surfaces the player must read, so the outline is part of usability rather than decoration.

## Considered Options

- Body color changes only.
- Body color plus outline or glow.
- HUD badge only.
- Particle aura only.
- No explicit feedback.

## Consequences

Visual validation should check that the Chameleon remains readable on matching and non-matching surfaces. The State Outline should support play clarity without becoming the dominant visual effect.
