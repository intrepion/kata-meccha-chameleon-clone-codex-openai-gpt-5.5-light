# Optional Sunfly collectibles

Meccha Chameleon will include optional Sunflies hidden in each Level rather than required collectibles, score-only fruit, paint ammo pickups, or key fragments. Sunflies add exploration texture without making level completion depend on scavenger gating.

## Considered Options

- No collectibles.
- Fruit pickups for score only.
- Three hidden Sunflies per Level.
- Paint drops that refill ammo.
- Key fragments required to Exit.

## Consequences

Sunflies should support replay and completion tracking, but the core acceptance path remains traversal, paint-rule mastery, and reaching the Exit.
